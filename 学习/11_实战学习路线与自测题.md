## 阶段 10：实机测试梯子

建议顺序：

```text
feature-off build
 -> feature-on build
 -> M=255/256/257 correctness
 -> q=2 全矩阵
 -> q=1/4
 -> repeated 1000
 -> profiler
 -> Qwen eager
 -> ACL Graph
 -> 长稳压测
```

为什么 M=255/256/257？

```text
255：baseM 以下/tail
256：精确边界
257：刚跨边界
```

边界最容易暴露：

```text
padding
batch count
arena offset
valid_rows
```

## 最终毕业题

不看当前实现，回答：

> 如果明天硬件换成 16 个 AI Core、MemFabric 新增 tile completion API、TP 变成 4，而且 DFlash 让 M 主要集中在 32～96，你会保留哪些 correctness 机制？哪些策略全部重做？为什么？
