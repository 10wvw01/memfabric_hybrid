# 13_bw_compare：IPC、VMM 与 host 中转带宽

## 测试内容

在同一设备对和同一数据大小上，对三种传输路径先做数据校验，再计时比较。

## 本轮条件与结果

2026-11-11，Ascend310P3 / Atlas 300I Duo，aarch64，CANN 9.2.1，驱动 26.1.0。

同卡 2→3 和跨卡 2→4；每次 16 MiB，3 次预热、30 次异步提交和最终同步。

**两组均通过，退出码 0。**

同卡 IPC/VMM/host 中转分别为 19.04/19.05/3.32 GB/s；跨卡分别为 11.88/12.11/3.82 GB/s。这里仅列两组实测，未覆盖所有 56 条有向链路。

## 运行

在仓库根目录执行，设备号以当前进程可见的编号为准：

```bash
source /usr/local/Ascend/cann/set_env.sh
A_DEV=2 B_DEV=3 bash 310p-capability_matrix/13_bw_compare/run.sh
```

脚本先编译，传递编译和运行的退出码；超时返回 124，超时后强制结束可能返回 137。
本轮条件、退出码与关键输出收录在[结果记录](../results/2026-11-11.json)。

跨卡复现时将命令改为 `A_DEV=2 B_DEV=4`。带宽单位为十进制 GB/s，中转带宽按交付的数据字节计算。
