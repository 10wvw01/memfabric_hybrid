## 1. 目标与固定路由

Ascend 310P3 / dav-2002，CANN 9.1，Qwen3.6-35B-A3B-w8a8，TP=2。
目标投影：10 层 Full Attention `self_attn.o_proj`、30 层 GDN `linear_attn.out_proj`，
对应 FP16 原始 NZ 权重、K_local=N=2048。

- `M < 2048` 或 `M > 4096`：原生 MM + HCCL AllReduce（Stock）；
- `2048 <= M <= 4096`：V2 T0 MM + MemFabric SDMA + Add 单 Kernel；
- 单用户最大输入 4096 tokens，模型 Forward 一次调度 token 预算 `max-num-batched-tokens=4096`，
  二者不是同一概念；输出基准 2048 tokens，并发 10。
- 严格收益基线：同场景原生 MM + HCCL Stock，要求吞吐提高、TTFT 和 TPOT 降低，
  P95/P99 不显著退化。
