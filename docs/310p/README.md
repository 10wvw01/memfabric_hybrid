# 310P 技术档案索引

> **目录定位**：310P（Atlas 300I Duo / Ascend310P3）平台长寿命技术知识的唯一归置处。
> 仓库根目录的三份过程文档（《memfabric-310p-内存池化方案》《310p-2rank-vmm-开发计划》
> 《310p-aicore-aicpu-开发进展》）已冻结为过程记录——技术内容**以本目录档案为准**，
> 行为契约以 `openspec/specs/` 为准。

## 按角色阅读路径

| 你是谁 | 读什么 | 目的 |

## 三份档案的边界

```
docs/310p/
├── 机制档案.md   —— 怎么构造和提交搬运指令（wire 级配方，hcomm 源码级证实）
├── 部署档案.md   —— 怎么把 kernel 弄上设备（deployer+KFC → 自部署 → OPP 三段演进）
└── 平台事实.md   —— 这块板子实测是什么行为（F 表/S 表/T 表，跨环境使用前复核）
```

## 与其他文档的关系

- **架构总览**：`docs/架构概览.md` 第 8 章平台表含 310P 行（协同模式接入位置）；
- **行为契约**：`openspec/specs/310p-shm-overlap/`（SHM 协同模式的开关门控/冒烟探测/
  API 语义等 SHALL 级要求，变更需走 OpenSpec change 流程）；
- **过程记录**：根目录三份文档保留完整的决策/验收/踩坑历史（含本文档未收录的
  进展细节），可作为深挖材料，但技术结论若与档案冲突，以档案为准。
